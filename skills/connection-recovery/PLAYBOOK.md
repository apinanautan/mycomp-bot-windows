# Verified recovery playbook

Add a reusable case only after a real repair is verified. Never log credentials, consent codes, personal folder paths, device identifiers or private endpoints.

## Case template
- Symptom: observable failure and channel
- Evidence: bounded diagnostic, result and tool
- Root cause: verified, not guessed
- Minimal fix: exact non-secret change
- Acceptance: independent read-only MCP/tool call and result
- Performance: task type, sample count and observed median, if available
- Rollback/risk: safe reversal and untested boundary
